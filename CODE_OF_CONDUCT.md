# Code of Conduct

## Our pledge

We as members, contributors, and leaders pledge to make participation in this
project a harassment-free experience for everyone, regardless of age, body size,
visible or invisible disability, ethnicity, sex characteristics, gender identity
and expression, level of experience, education, socio-economic status,
nationality, personal appearance, race, caste, colour, religion, or sexual
identity and orientation.

We pledge to act and interact in ways that contribute to an open, welcoming,
diverse, inclusive, and healthy community.

## The standard we adopt

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The canonical text — the full standards, the scope, and the
enforcement guidelines with their four-step ladder (correction, warning,
temporary ban, permanent ban) — is published at:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md>

It is adopted by reference rather than copied here, so that the text this
project enforces is the published text and not a paraphrase of it.

## Reporting

Report abusive, harassing, or otherwise unacceptable behaviour to the
maintainer, [@tkittich](https://github.com/tkittich), through GitHub. If the
report concerns a public thread, use the *Report content* option on the comment
itself; otherwise open a minimal issue asking for a private channel and include
no details, in the same way
[SECURITY.md](SECURITY.md#reporting-a-vulnerability) handles a vulnerability
report.

All complaints will be reviewed and investigated promptly and fairly, and the
privacy and security of the reporter will be respected.

## Scope

This code applies in all project spaces — issues, pull requests, discussions,
commit messages, code comments and review — and when an individual is
officially representing the project in public.
